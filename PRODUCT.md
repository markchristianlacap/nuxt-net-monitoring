# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Small IT teams monitoring shared network infrastructure and internet connectivity.

## Product Purpose

Nuxt Net Monitoring gives a small IT team historical visibility into network performance so they can understand trends and investigate connectivity issues over time.

## Positioning

The product combines SNMP-based network bandwidth monitoring with live and scheduled internet speed tests in one self-hosted monitoring workspace, rather than treating device traffic and internet performance as separate systems.

## Operating Context

The application is used by authenticated operators on a trusted network to monitor configured network devices and review recorded performance results.

## Capabilities and Constraints

- Monitor bandwidth from SNMP-enabled network devices and interfaces.
- Run live and scheduled internet speed tests.
- Retain and review historical bandwidth and speed-test results.
- Preserve support for PostgreSQL-backed persistence and authenticated access.

## Product Principles

- Make historical network behavior easy to understand.
- Keep bandwidth and internet performance in the same operational view.
- Favor useful evidence over unexplained status indicators.
- Keep monitoring private and operator-controlled.

## Accessibility & Inclusion

No product-specific accessibility requirements have been established yet; future work should preserve accessible web interaction patterns.
